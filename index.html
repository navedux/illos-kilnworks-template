Ship a job in three steps

A job is a function in your repo. There are no workers to run and no servers to patch.

  1. 01

    Write the job

    Give a function a name and say how many times it may retry. It lives next to the code that calls it.

    • TypeScript, Python or Go
    • Runs on your laptop too
    jobs/send-receipt.ts 
    import { job } from "kilnworks";

export const sendReceipt = job({
  id: "send-receipt",
  retries: 5,
  run: async ({ orderId }) => {
    await mail.receipt(orderId);
  },
});

  2. 02

    Push it

    Every push to main builds your jobs, tests them and rolls them out. Runs already in flight finish on the old version.

    • A preview queue per branch
    • Roll back in one click
    Terminal 
    $ git push origin main
build   3 jobs found
test    12 passed in 4.1s
ship    live in 9s

  3. 03

    Call it from your app

    Enqueue from any route and return right away. The job runs on Kilnworks workers, which grow and shrink with your queue.

    • Delay or schedule any call
    • Track each run by its id
    app/checkout.ts 
    await sendReceipt.enqueue({
  orderId: order.id,
});
// returns in about 4 ms

Built for the day something breaks

Payment APIs go down and deploys go wrong. Kilnworks keeps the work safe until it can finish.

  • Retries that back off

    A failed job tries again later, and later still, up to 25 times.

  • A queue for jobs that gave up

    Nothing is thrown away. Fix the bug, then replay them in one click.

  • Run-once keys

    Enqueue the same key twice and the job still runs once.

  • Rate limits

    Stay under a fussy partner API’s limit, per second or per minute.

  • Fair share for every customer

    Cap how many jobs one account runs at once, so a big export never starves the rest.

  • A log of every attempt

    Input, output, errors and timing for each try, searchable for 30 days.

  • Alerts before customers notice

    Hear about it in chat or email when a queue backs up or a job keeps failing.

  • Your data stays in your region

    Run and store jobs in the US or the EU, and keep payloads encrypted at rest.
